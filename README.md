## 1. Sobre o sistema

O StockControl é um sistema utilizado para controlar produtos, entradas, saídas e estoque de uma empresa.

## 2. Público-alvo

Este manual é destinado aos funcionários responsáveis pelo controle de estoque.

## 3. Como acessar

### Requisitos

- Computador ou celular
- Conexão com a internet
- Usuário cadastrado

### Passo a passo

1. Acesse o sistema.
2. Informe seu usuário.
3. Digite sua senha.
4. Clique em **Entrar**.

## 4. Cadastro de produto

1. Acesse o menu **Produtos**.
2. Clique em **Novo produto**.
3. Informe o nome do produto.
4. Informe o código do produto.
5. Informe a quantidade inicial.
6. Clique em **Salvar**.

## 5. Entrada de estoque

1. Acesse **Estoque**.
2. Selecione **Entrada**.
3. Informe o produto.
4. Informe a quantidade.
5. Confirme a operação.

## 6. Saída de estoque

1. Acesse **Estoque**.
2. Selecione **Saída**.
3. Informe o produto.
4. Informe a quantidade.
5. Confirme a operação.

## 7. Problemas comuns

Esta seção apresenta procedimentos para identificar e solucionar problemas frequentes no sistema.

### 7.1 Não consigo fazer login

**Problema:**  
O usuário não consegue acessar o sistema utilizando suas credenciais.

**Possíveis causas:**

- Usuário informado incorretamente.
- Senha informada incorretamente.
- Usuário não cadastrado.
- Falha na conexão com a internet.

**Procedimento para solução:**

1. Verifique se o usuário foi digitado corretamente.
2. Verifique se a senha foi digitada corretamente.
3. Confirme se o usuário está cadastrado no sistema.
4. Verifique a conexão com a internet.
5. Tente realizar o login novamente.

**Se o problema continuar:**

Entre em contato com o suporte técnico e informe:

- Nome do usuário.
- Data e horário do problema.
- Mensagem de erro apresentada.
- Procedimentos realizados antes de solicitar suporte.

---

### 7.2 Não consigo cadastrar um produto

**Problema:**

O usuário não consegue cadastrar um novo produto no sistema.

**Possíveis causas:**

- Campos obrigatórios não foram preenchidos.
- O código do produto já está cadastrado.
- O usuário não possui permissão para cadastrar produtos.
- Ocorreu uma falha de conexão com o sistema.

**Passos para solução:**

1. Verifique se todos os campos obrigatórios foram preenchidos.
2. Verifique se o código do produto já existe no sistema.
3. Confirme se o usuário possui permissão para cadastrar produtos.
4. Verifique a conexão com a internet.
5. Tente cadastrar o produto novamente.

**Se o problema continuar:**

Entre em contato com o suporte técnico e informe:

- Nome do usuário.
- Nome ou código do produto.
- Data e horário do problema.
- Mensagem de erro apresentada pelo sistema.

### 7.3 Estoque não foi atualizado

**Problema:**

O estoque não apresenta a quantidade correta após uma entrada ou saída de produtos.

**Possíveis causas:**

- A operação não foi confirmada.
- A quantidade informada está incorreta.
- O produto selecionado está incorreto.
- O sistema não atualizou as informações.

**Passos para solução:**

1. Verifique se a operação foi confirmada.
2. Confira a quantidade informada.
3. Confirme se o produto correto foi selecionado.
4. Atualize a página do sistema.
5. Consulte novamente o estoque.

**Se o problema continuar:**

Entre em contato com o suporte técnico e informe:

- Nome do usuário.
- Produto afetado.
- Quantidade informada.
- Tipo de operação realizada.
- Data e horário do problema.

## 8. Suporte

Caso o problema não seja solucionado pelos procedimentos deste manual, solicite atendimento ao suporte técnico.
