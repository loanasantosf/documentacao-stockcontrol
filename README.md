## 1. Sobre o sistema

O StockControl é um sistema utilizado para controlar produtos, entradas, saídas e estoque de uma empresa.

## 2. Público-alvo

Este manual é destinado aos funcionários responsáveis pelo controle de estoque.

## 3. Como acessar

### Requisitos

- Computador ou celular
- Conexão com a internet
- Usuário cadastrado

### Passo a passo

1. Acesse o sistema.
2. Informe seu usuário.
3. Digite sua senha.
4. Clique em **Entrar**.

## 4. Cadastro de produto

1. Acesse o menu **Produtos**.
2. Clique em **Novo produto**.
3. Informe o nome do produto.
4. Informe o código do produto.
5. Informe a quantidade inicial.
6. Clique em **Salvar**.

## 5. Entrada de estoque

1. Acesse **Estoque**.
2. Selecione **Entrada**.
3. Informe o produto.
4. Informe a quantidade.
5. Confirme a operação.

## 6. Saída de estoque

1. Acesse **Estoque**.
2. Selecione **Saída**.
3. Informe o produto.
4. Informe a quantidade.
5. Confirme a operação.

## 7. Problemas comuns

Esta seção apresenta procedimentos para identificar e solucionar problemas frequentes no sistema.

### 7.1 Não consigo fazer login

**Problema:**  
O usuário não consegue acessar o sistema utilizando suas credenciais.

**Possíveis causas:**

- Usuário informado incorretamente.
- Senha informada incorretamente.
- Usuário não cadastrado.
- Falha na conexão com a internet.

**Procedimento para solução:**

1. Verifique se o usuário foi digitado corretamente.
2. Verifique se a senha foi digitada corretamente.
3. Confirme se o usuário está cadastrado no sistema.
4. Verifique a conexão com a internet.
5. Tente realizar o login novamente.

**Se o problema continuar:**

Entre em contato com o suporte técnico e informe:

- Nome do usuário.
- Data e horário do problema.
- Mensagem de erro apresentada.
- Procedimentos realizados antes de solicitar suporte.

---

### 7.2 Produto não aparece no estoque

**Problema:**  
O produto foi cadastrado, mas não aparece na consulta de estoque.

**Possíveis causas:**

- Produto cadastrado incorretamente.
- Entrada de estoque não registrada.
- Quantidade informada incorretamente.

**Procedimento para solução:**

1. Acesse o menu **Produtos**.
2. Pesquise pelo nome ou código do produto.
3. Confirme se o cadastro está correto.
4. Acesse o menu **Estoque**.
5. Verifique se a entrada do produto foi registrada.
6. Caso necessário, registre a entrada de estoque.

**Resultado esperado:**

O produto deve aparecer na consulta de estoque com a quantidade atualizada.

---

### 7.3 Quantidade do estoque está incorreta

**Problema:**  
A quantidade apresentada no sistema é diferente da quantidade física disponível.

**Procedimento para solução:**

1. Confira fisicamente a quantidade do produto.
2. Consulte as últimas entradas de estoque.
3. Consulte as últimas saídas de estoque.
4. Identifique possíveis lançamentos incorretos.
5. Solicite a correção ao responsável pelo estoque, caso necessário.

**Resultado esperado:**

A quantidade registrada no sistema deve corresponder à quantidade física disponível.
## 8. Suporte

Caso o problema não seja solucionado pelos procedimentos deste manual, solicite atendimento ao suporte técnico.
